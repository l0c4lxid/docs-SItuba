# Panduan Utama Kader TBC Lapangan (Field Officer)

Halaman ini berisi petunjuk penggunaan aplikasi SItuba khusus untuk **Bapak/Ibu Kader TBC Lapangan**.

Sebagai garda terdepan penanggulangan Tuberkulosis, Kader bertugas melakukan penjangkauan langsung ke rumah warga (*door-to-door*), mendeteksi gejala batuk berisiko, mencatat formulir skrining digital, dan menghubungkan warga suspek ke Puskesmas Pembina.

---

## 1. Tampilan Layar Utama (Dashboard Kader)

Setelah berhasil masuk (*login*) menggunakan nomor HP dan kata sandi akun Kader, layar HP atau komputer akan menampilkan dashboard personal kader.

[![Dashboard Personal Kader TBC Lapangan](/img/kader/dashboard.png)](/img/kader/dashboard.png)

:::tip
Klik atau sentuh gambar di atas untuk melihat tampilan ukuran penuh di HP/komputer Bapak/Ibu.
:::

---

## 2. Struktur Menu Navigasi Kader

Pada menu bilah sebelah kiri (*Sidebar*), tersedia modul-modul tugas harian:

| Menu | Fungsi Sistem Informasi |
| :--- | :--- |
| **Dashboard** | Halaman ringkasan performa pendataan dan tombol cepat mulai skrining baru. |
| **Mitra** | Informasi Puskesmas Induk pembina kader dan daftar kelurahan wilayah penugasan. |
| **Skrining** | Formulir input skrining baru dan tabel riwayat seluruh warga yang telah diperiksa. |
| **Materi** | Buku panduan teknis kader interaktif dan modul edukasi penyuluhan warga. |
| **Berita** | Portal artikel edukasi kesehatan dan ruang berbagi cerita/testimoni kader lapangan. |
| **Profil Saya** | Pengaturan identitas kader, wilayah RT/RW penugasan, dan ubah kata sandi akun. |

---

## 3. Cara Membaca 3 Kartu Capaian Kinerja Kader

Di bagian atas dashboard terdapat 3 kartu indikator kerja mandiri:

1. **Skrining Dicatat (Total Warga Diperiksa):** Akumulasi warga yang berhasil Bapak/Ibu data dan simpan ke dalam sistem SItuba.
2. **Suspek Ditemukan (Warga Terindikasi):** Jumlah warga yang mengalami gejala batuk/demam yang perlu tes dahak di Puskesmas.
3. **Kinerja Bulan Ini:** Jumlah capaian penjangkauan skrining yang berhasil diselesaikan pada bulan berjalan.

---

## 4. Tombol Cepat [+ Mulai Skrining Baru]

Untuk memulai pendataan saat berkunjung ke rumah warga, Bapak/Ibu dapat langsung menekan tombol biru **[+ Mulai Skrining Baru]** di bagian atas dashboard untuk langsung membuka formulir pemeriksaan.

---

## 5. Pengaturan Profil & Kontak Kader

- **Langkah 1:** Klik menu **Profil Saya** di sebelah kiri.
- **Langkah 2:** Pastikan nama lengkap, nomor WhatsApp aktif, dan wilayah kerja RT/RW sudah sesuai agar memudahkan koordinasi dengan Puskesmas dan Kelurahan.
