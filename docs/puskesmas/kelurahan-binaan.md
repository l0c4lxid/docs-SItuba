# Cara Memantau Kelurahan Binaan

Puskesmas Pembina dapat melihat daftar Kelurahan yang berada di bawah wilayah kerjanya untuk memastikan koordinasi pembinaan kader TBC berjalan lancar.

---

## 1. Membuka Menu Kelurahan Binaan

- **Langkah 1:** Klik menu **Kelurahan Binaan** di sebelah kiri layar.
- **Langkah 2:** Bapak/Ibu dapat melihat daftar kelurahan yang terhubung langsung dengan Puskesmas Bapak/Ibu beserta status keaktifannya.

[![Daftar Kelurahan Binaan Puskesmas](/img/puskesmas/data_kelurahan.png)](/img/puskesmas/data_kelurahan.png)

:::tip
Klik gambar di atas untuk melihat tampilan ukuran penuh.
:::

---

## 2. Koordinasi dan Pemantauan Wilayah

- **Cari Kelurahan:** Gunakan kolom **Cari nama / alamat** di atas tabel untuk mencari kelurahan secara cepat.
- **Status Hubungan:** Status **Aktif** menandakan data kader dan skrining dari kelurahan tersebut telah otomatis terhubung ke dashboard Puskesmas Bapak/Ibu.
- **Lepas / Kelola Hubungan:** Tombol **[Lepas]** digunakan jika penugasan wilayah kelurahan binaan dialihkan ke Puskesmas lain oleh Dinas Kesehatan.
