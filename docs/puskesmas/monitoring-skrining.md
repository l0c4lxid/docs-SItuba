# Cara Memantau Pasien Suspek TBC Wilayah

Halaman **Data Skrining** digunakan oleh Puskesmas untuk melihat daftar warga terindikasi suspek TBC yang memerlukan tindak lanjut tes dahak (TCM).

---

## 1. Membuka Daftar Pemeriksaan Pasien

- **Langkah 1:** Klik menu **Data Skrining** di sebelah kiri.
- **Langkah 2:** Pilih filter **Suspek TBC** di atas tabel untuk menampilkan warga yang memiliki gejala batuk/demam.

[![Tabel Data Skrining Wilayah Puskesmas](/img/puskesmas/data_skrining.png)](/img/puskesmas/data_skrining.png)

:::tip
Klik gambar di atas untuk memperbesar.
:::

---

## 2. Tindak Lanjut Rujukan Tes Dahak

- Catat nama, alamat, dan nomor HP warga terindikasi suspek.
- Hubungi warga atau Kader pendamping untuk menjadwalkan pengambilan contoh dahak atau pemeriksaan langsung di Puskesmas.
- Klik tombol hijau **[Export Excel]** untuk mengunduh laporan daftar pasien suspek ke dalam file Excel.
